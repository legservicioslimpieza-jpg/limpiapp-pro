# LimpiApp Pro — LEG Servicios de Limpieza

Sistema de gestión operacional para empresas de aseo.

## Funcionalidades
- Dashboard con KPIs en tiempo real
- Gestión de trabajadores
- Checklist por dependencia (Diaria / Semanal / Mensual)
- Registro de incidencias con seguimiento de estados
- Supervisiones con % de cumplimiento
- Generación de informes con IA (requiere API key de Anthropic)

## Cómo publicar en Vercel (sin instalar nada)

1. Sube esta carpeta a GitHub:
   - Ve a github.com → New repository → "limpiapp-pro"
   - Arrastra todos estos archivos

2. Ve a vercel.com:
   - "Add New Project"
   - Importa el repositorio "limpiapp-pro"
   - Haz clic en "Deploy"
   - ¡Listo! En 2 minutos tienes tu URL

## Desarrollo local (opcional)

```bash
npm install
npm run dev
```

Luego abre: http://localhost:5173

## Construir para producción

```bash
npm run build
```
